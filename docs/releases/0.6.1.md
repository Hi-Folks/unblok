# Unblok 0.6.1

This release makes it easier to see and fill gaps in your Storyblok Dimensions content.

## Check coverage across countries

Use `dimensions coverage` to find linked and missing variants for stories under a selected folder:

```bash
unblok dimensions coverage \
  --starts-with global/articles/ \
  --space-id YOUR_SPACE_ID
```

Unblok discovers the configured Dimensions folders and shows results as each story is checked. Add `--folder` to focus on specific countries, or `--json` for automation.

## Create missing variants

Preview missing variants, then create them across selected country folders:

```bash
unblok dimensions create-missing \
  --starts-with global/articles/ \
  --folder italy \
  --folder germany \
  --space-id YOUR_SPACE_ID \
  --plan
```

Replace `--plan` with `--yes` to create them. Existing linked variants are preserved. The operation is also available through YAML and the JavaScript library.

## Prepare a Dimensions demo

A new [modular YAML example](../../examples/features/setup-dimensions-demo.yaml) combines app installation, country-folder setup, global content organization and creation of linked article variants.

## More improvements

- `story compare-dimensions` checks all configured destination folders by default.
- Bulk variant creation shows live progress and supports start pages with trailing slashes.
- Setup schema descriptions provide more helpful guidance in YAML editors.
