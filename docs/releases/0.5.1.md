# Unblok 0.5.1

This release adds read-only tools for finding and understanding Storyblok content.

- **Find stories** with filters for names, content, slug prefixes, contained blocks, tags and publication status.
- **Compare field-level translations** against default story values, including nested blocks and missing or empty stored values.
- **Explore story history** and compare the content of two versions, or use `--previous` to compare a draft with preceding history content.
- **Get more reliable history results** when Storyblok returns fewer versions per page than requested. Previous-version comparison includes non-release workflow-stage snapshots.

These operations are available through the CLI and JavaScript library. History uses Storyblok's current versions endpoint, which covers versions created after August 28, 2024. The previous-version shortcut was verified for a story in a live space.
