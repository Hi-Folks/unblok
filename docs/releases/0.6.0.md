# Unblok 0.6.0

This release brings tools for managing content across Storyblok Dimensions: organize a space into country folders, compare linked stories, and selectively share content between them.

## Compare and cherry-pick content

- Compare linked stories across Dimensions folders and inspect their content differences.
- Preview and synchronize selected block fields between stories—for example, share a global hero image while preserving local text.
- Preview and update all blocks in a story that match an exact field condition.

These operations are available through the CLI and JavaScript library. Selected-field synchronization and matching-block updates are also available in YAML.

## Organize content for Dimensions

- Configure and list Dimensions folders.
- Create linked story variants and request merges between stories.
- Move stories into folders, organize root content under a shared folder, and create draft story copies.
- Use the new country-folder setup and field synchronization recipes to adapt these workflows to your space.

## Find content and understand results

- Filter story lists by content fields using CLI options or the JavaScript library.
- Read Dimensions comparisons and resource lists in labeled, width-aware terminal tables.
- Use `--verbose` for safe API error diagnostics, including Dimensions duplication failures.

## Fixes

- Match the Dimensions UI duplication request when creating linked variants.
- Preserve recognized, non-sensitive Storyblok validation details in shared action errors.
