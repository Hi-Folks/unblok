# Unblok 0.5.0

Unblok is easier to use with AI coding agents and automation. The new Unblok skill helps agents choose the CLI, YAML blueprints, or JavaScript library for a Storyblok task, with guidance for translation and campaign workflows.

- Install the skill for Codex or Claude Code with `unblok skill install --agent codex` or `--agent claude`.
- Get actionable blueprint validation errors, including field paths and suggestions for likely typos.
- Inspect structured error codes and HTTP statuses for individual failed YAML operations.
- Retrieve the installed CLI's blueprint JSON Schema locally with `unblok space setup schema --json`.
- Find bundled campaign and translation YAML examples with `unblok space setup examples`.
- Discover options, examples, and important side effects in the setup, release, and translation command help.
- See whether translation requests are queued without implying background work has completed.
- Build a standalone executable for your machine with `bun run buildexe`.

## Structured results

With `--json`, CLI errors are JSON objects on stderr. Some failed operations also return a partial-results report on stdout; inspect both streams and the exit code.

Blueprint validation errors may include an `issues` array containing paths and messages. When blueprints use `extends`, these paths refer to the resolved blueprint rather than a specific source file.

The skill is maintained in the GitHub repository and installed separately; it is not automatically activated when installing the npm package.
